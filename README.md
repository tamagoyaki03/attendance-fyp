# Anti Fraud Attendance Management System

## Overview
A full-stack anti fraud attendance management system for organizers side (administrator and lecturers).

## Tech Stack
- React
- Material UI
- Supabase
- JavaScript

## Features
- User Authentication
- Role-Based Access Control
- Attendance Tracking
- Absence Management
- Analytics Dashboard

## Project Architecture
Frontend (React + MUI)
↓
Supabase Authentication
↓
Supabase Database
